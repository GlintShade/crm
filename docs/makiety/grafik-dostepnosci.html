Wpisywanie grafiku przez backoffice

Trzy sposoby do wyboru, wszystkie zmieniają te same dane, więc wynik od razu widać na kartach (i na zakładce 1). Wpisywać mogą: System Manager, Volteo Core Admin, Volteo Backend.

Model danych (propozycja)

Nowy doctype Volteo Dostepnosc: jeden rekord to jeden dzień jednego handlowca z jednym oknem dostępności (od, do) albo z zaznaczonym dniem wolnym. Dzień bez rekordu znaczy "brak grafiku" (zachowanie wg pytania 3). Stały grafik tygodniowy, jeśli go wybierzesz, zapisujemy jako rekordy z dzien_tygodnia zamiast data, a konkretna data nadpisuje stały wzór. Zapis: System Manager, Volteo Core Admin, Volteo Backend (nowa metoda crm.api.kalendarz.ustaw_dostepnosc, walidacja w frappe-free crm/volteo_kalendarz.py). Odczyt: wszystkie role tablicy, handlowiec tylko swoje. crm.api.kalendarz.spotkania zwraca obok spotkania nowy klucz dostepnosc: {user: {"2026-11-02": [["08:00", "22:00"]], "2026-11-06": []}}, gdzie pusta lista to dzień wolny, brak daty to brak grafiku, a front liczy z tego ciemne odcinki (czysta funkcja w utils/kalendarz.js, z testami).
